In this repository, add duplicate-row detection to csvcheck.validate. A data row whose parsed fields equal those of an earlier data row is reported as Problem(line, 'duplicate-row', 'same as line N'), where N is the first occurrence. The header is not a data row, blank lines are ignored but still count toward line numbers, rows with the wrong column count are reported as before and are not compared, whitespace inside a field is significant, and problems stay ordered by line. Keep the existing tests passing and add tests for the new behavior.
