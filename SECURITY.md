# Security policy

Report a vulnerability privately through GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability). Please don't open a public issue for it.

Flightdeck holds no sandbox or provider credentials (docs/decisions/0001-boundary-with-hangar.md). If you find team
data in this public repository (traces, Parquet, mined tasks, sealed holdout material), report it the same way so it
can be removed from history (docs/decisions/0002-public-code-private-data.md).
